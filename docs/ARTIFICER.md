# Artificer coverage

The selectable Artificer class uses the 95-spell base list in Tasha’s Cauldron of Everything (2020), printed page 12, checked against the supplied local book. The class is explicitly marked as earlier rules in both languages. Existing explicit Artificer assignments from supplements remain available: 99 spells total. The catalogue still contains 537 distinct spells.

The overlay adds class access to existing catalogue records, never additional copies. PHB 2024 and verified Arcana Unleashed revisions keep their priority. Single-class spell levels unlock at character levels 1, 5, 9, 13 and 17; cantrips are available from level 1. Character books and manual preparation use the existing storage model. Subclass additions are not automatic.

The final Eberron: Forge of the Artificer (2025) class list is not verified from the available books. Do not label the Tasha list as the final revised class. The official overview confirms that the revised class changes preparation to a fixed count and grants Mending through Tinker’s Magic; those class features are not implemented by this spell catalogue:
https://www.dndbeyond.com/posts/2106-whats-new-with-the-artificer-in-eberron-forge-of
